# ReciReflect questionnaire

An anonymous questionnaire about ReciReflect, a transparent recipe recommender with an AI supervisor.

**Take it here: https://amirmohammad-nouri.github.io/recireflect-questionare/**

Or download [`index.html`](https://raw.githubusercontent.com/AmirMohammad-Nouri/recireflect-questionare/main/index.html)
(right-click → *Save link as…*) and open it in any web browser. It works offline.

- **Part 1:** ten features of the app, each shown with and without the feature.
- **Part 2:** ten fictional cases, each lived with three versions of the supervisor.
- About 25 minutes. No name, email or other personal detail is asked, and nothing is sent anywhere.

When you finish, press **Save as JSON** and send the file to the person who gave you the link.
